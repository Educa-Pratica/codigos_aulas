# Ícones para Apresentações

Pacote de ícones SVG minimalistas e consistentes.

## Características
- Formato SVG
- Estilo outline
- ViewBox 24 × 24
- Stroke consistente de 1.8
- Uso de `currentColor` para facilitar recoloração

## Uso
Os arquivos podem ser inseridos diretamente em:
- PowerPoint
- Google Slides
- Figma
- Canva

## Ícones
AI, Analytics, Arrow Right, Check, Chart Bar, Chart Line, Cloud,
Database, Globe, Lightbulb, Lock, People, Rocket, Settings, Target,
Trend Up e Warning.
